   - **Cold-Page Compression & RoPE Precision Control**: Fine-grained position embedding precision (`skip_rope_quantization=True` or `2FP4` with `nvfp4_residual_dim=64`) to preserve deep reasoning and coder performance across 16k+ context lengths.
